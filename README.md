# Tic Tac Toe Game

A simple and interactive two-player Tic Tac Toe game developed using HTML, CSS and JavaScript.

## Live Demo

https://subnc.github.io/tic-tac-toe/

## About the Project

This project is a web-based implementation of the classic Tic Tac Toe game.

The game is played between two players. Player X starts the game, followed by Player O. The application automatically checks for winning combinations and detects a draw when all cells are filled.

## Features

- Two-player Tic Tac Toe game
- 3×3 game board
- Automatic player turn switching
- Winner detection
- Draw detection
- X and O score tracking
- Restart Game option
- Reset Score option
- Green, Blue and Dark themes
- Winner cell highlighting
- Responsive design for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
